#  PadPad
A simple macropad built for stardance mission, consists of 5 key switches, a rotary encoder and uses Seeduino XIAO RP2040.
It utilizies Direct Pins instead of Keyboard Matrix.

## Dimensions

PCB Dimensions: 65mm x 64mm
Case Dimensions: 84.90mm x 84.50mm x 16mm

## BOM

- 5x Cherry MX 1.00u Switches
- 1x Rotary encoder with switch
- 1x Seeduino XIAO RP2040
- PCB Fabrication
- 3D Printing
